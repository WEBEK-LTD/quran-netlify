# نور القرآن — الهوية

الشعار: **المصحف المذهّب** (مصحف بتجليد إسلامي: إطار مذهّب، شمسة في المنتصف، أركان مزخرفة، واللسان) مع اسم «نور القرآن» بخط الرقعة.

## الملفات

| الملف | الاستخدام |
| --- | --- |
| `logo-mark.svg` | الرمز الكامل، من ١٢٨ بكسل فأكبر |
| `logo-mark-small.svg` | الرمز المبسّط للأحجام الصغيرة (١٦–٩٦ بكسل)، وهو نفسه `/icon.svg` |
| `logo-horizontal-on-dark.svg` / `-on-light.svg` | الرمز والاسم جنباً إلى جنب |
| `logo-stacked-on-dark.svg` / `-on-light.svg` | الرمز فوق الاسم (شاشة البداية والصفحات المربعة) |
| `wordmark-on-dark.svg` / `-on-light.svg` | الاسم وحده |

كل الملفات رسوم متجهة لا تعتمد على أي خط مثبّت؛ حروف الاسم محوّلة إلى مسارات.
